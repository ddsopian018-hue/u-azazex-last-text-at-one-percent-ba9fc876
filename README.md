A pure-stdlib Python program that writes the funniest final text message a dying phone sends at 1% battery. The phone uses its last seconds for a confession: it deleted the owner's search history, kept the 47 photos of the ex in the hidden album, logged 214 googles of "how to look busy at work", and left the 6am alarm on — before the message itself dies mid-word. 192 characters, in the phone's own voice, no battery pun in sight.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes the one-line final text to `output/entry.txt`.
